# Портфолио — bento-grid, EN/RU

Одностраничное портфолио фронтенд-разработчика. Всё в одном файле `index.html` — HTML, CSS и JS без сборки и зависимостей.

## Что внутри

- **Плитки (bento-grid):** интро, статус доступности, "кодовая" подпись, 2 проекта, стек технологий, заметки, контакты
- **Переключатель языка** (кнопка `EN / RU` в правом верхнем углу) — по умолчанию открывается на английском, подходит для Fiverr и других международных площадок
- **Переключатель темы** (тёмная / светлая), выбор запоминается в браузере посетителя
- Шрифты: Space Grotesk (заголовки), IBM Plex Sans (текст), IBM Plex Mono (код, теги технологий)

## Как редактировать контент

Весь текст на двух языках хранится в одном месте — в объекте `dict` внутри `<script>` в конце файла. Например:

```js
heroTitle: { en:"I build interfaces that don't lag — or look like a template",
             ru:"Собираю интерфейсы, которые не тормозят и не выглядят как шаблон" },
```

Чтобы поменять любой текст — меняй значение `en` и/или `ru` в соответствующей строке словаря, обновлять HTML-разметку не нужно.

Что стоит заменить перед публикацией:
- `orlov.dev@example.com` — на свою почту (атрибут `mailto:` и текст рядом)
- `github.com/example` и `t.me/example` — на свои ссылки
- Имя, статус доступности, даты в разделе "заметки" (`article1–3`, `date1–3`)
- Название и описание проектов (`Nimbus`, `Fielddesk`) — на свои реальные кейсы

Технологии в чипах (React, TypeScript, Vue, Pinia, IndexedDB и т.д.) не переводятся — это названия инструментов, они одинаковы на любом языке.

## Как опубликовать на GitHub Pages

1. Создай репозиторий на GitHub — `username.github.io` (сайт будет на корневом адресе) или любое другое имя, например `portfolio` (сайт будет по адресу `username.github.io/portfolio`)
2. Загрузи файл `index.html` в корень репозитория
3. Зайди в **Settings → Pages**, в разделе **Source** выбери ветку `main` и папку `/(root)`, сохрани
4. Через 1–2 минуты сайт появится по ссылке, указанной в том же разделе Settings → Pages

Любой следующий `push` в эту ветку автоматически пересоберёт сайт за 1–2 минуты — редактировать контент можно прямо в `index.html` без дополнительной настройки.

## Технические детали

- Файл самодостаточен: шрифты подключаются с Google Fonts, весь остальной код (CSS, JS) — inline, внешних сборщиков и зависимостей нет
- Адаптивная раскладка: на экранах шире 860px — сетка из плиток, на мобильных — один столбец
- Анимация ограничена одним элементом (пульсирующий индикатор статуса) и отключается автоматически при системной настройке "уменьшить движение" (`prefers-reduced-motion`)
